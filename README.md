#📊 Reliance Stock Market Dashboard

This project is an interactive data visualization dashboard analyzing stock performance of Reliance Industries Limited using historical market data.

🚀 Overview

The dashboard provides insights into stock trends including price movement, trading volume, and yearly/monthly performance using visually rich charts.

📈 Key Features
📅 Year-wise Analysis
Sum of closing price trends
Total traded volume by year
High price distribution
📊 Quarterly Insights
Average price comparison across quarters
📆 Monthly Trends
Price fluctuations across months
🔍 Combined Metrics
Open vs Close price comparison over time
